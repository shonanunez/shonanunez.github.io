# Shóna Nunez Apps

The source for [snapps.ie](https://snapps.ie), featuring Poppello and upcoming apps.

Built with HTML, CSS and JavaScript, hosted on GitHub Pages.

## Local preview

Run `python3 -m http.server 8000` and open <http://localhost:8000/>.

After changing shared CSS or JavaScript, run `python3 scripts/version-assets.py`
to refresh the asset cache keys.
